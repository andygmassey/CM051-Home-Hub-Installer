# FILES CARRYING AN INTENT COMMENT ON A NUMERIC *_level ASSIGNMENT.
#
# Rows are 'path<TAB>count'. Checked by
# tests/test_level_comments_state_direction_not_intent.py, which carries the
# predicate in full. In short: a comment on a privacy number must name the
# number, either as its level (L0Personal, L2Trusted) or by restating the value
# alongside a direction word. A comment that states the INTENT and no value
# cannot be checked against anything on its own line, and that is exactly how
#
#     compartment_level=5,  # HIGHEST PRIVACY
#
# shipped for Apple Notes and Apple Health. 5 is L5Commercial, which
# vendor/cm041/contact_syncer/privacy_model.py maps to publishable. The prose
# was right, the number was wrong, and review read the prose. The required form
# is
#
#     compartment_level=0,  # L0Personal, the most private level
#
# See docs/PRIVACY_LEVELS.md.
#
# ---------------------------------------------------------------------------
# THIS IS A RATCHET, AND THE COUNT IS LOAD-BEARING
# ---------------------------------------------------------------------------
# The ceiling may only DECREASE. A new path is a failure, and so is a higher
# count on a path already listed: violations ACCUMULATE inside a file, so a
# name-only row would let a listed file take on new ones for ever under a green
# verdict. That hole was proved by mutation in the sibling ratchet
# tests/pipefail_shortcircuit_baseline.txt and it is not repeated here.
#
# A count that DROPS is also a failure, with a different remedy: lower it, in
# the same commit as the fix. Slack left behind is room the count grows back
# into without anyone seeing it move.
#
# ---------------------------------------------------------------------------
# THE POPULATION
# ---------------------------------------------------------------------------
# Every file in the tree except .git, tests/ and */tests/, docs/ and */docs/,
# and cut-manifests/. Each exclusion has a seeded discriminator in the test, so
# it is proved rather than merely written down. Tests, docs and cut manifests
# QUOTE the banned line in order to warn about it; counting them would mean the
# only route to green is to stop warning.
#
# ---------------------------------------------------------------------------
# MEASURED 2026-09-16 on the committed tree, and these are the numbers the gate
# itself prints on every run
# ---------------------------------------------------------------------------
#   1184 text files examined
#     18 binary files skipped (icons and fonts; a NUL in the first block)
#      0 TEXT files that would not decode
#     37 numeric *_level assignments
#      3 further assignments skipped because they sit inside a comment
#     10 of the 37 carry a comment at all
#      6 violations, in 2 files
#
# THREE OF THOSE 37 ARE THIS GATE'S OWN MUTATION PAYLOADS, sitting in
# .github/workflows/privacy-scale-gates.yml, which is deliberately NOT excluded.
# They are not violations because the '#' in each sits inside a quoted shell
# string, and comment_start() masks string literals before it looks for a
# comment marker. That is designed behaviour carrying its own unit control
# ("a # inside a string literal is not a comment"), not an accident of this
# tree, and it was measured rather than assumed before this landed. With the
# workflow taken out, the same scan reads 1183 text files and 34 assignments.
#
# WHY NEITHER IS FIXED HERE. Both are vendored CM019 parser code on the install
# path, and both of the remaining apple.py sites are about what a customer's
# data is LABELLED as, not about comment style.
